# Decisions

This directory records the decisions that shape this repository, one file per decision.

Each file is named `YYYY-MM-DD-<outcome-slug>.md`: the date of the decision, then a short
description of its outcome. The file starts with a heading that states the outcome and the date,
then says what was chosen and why, what was not chosen and why it lost, and who confirmed it
(or that nobody has yet).

A new decision is a new file. Earlier files are not rewritten; a later decision that replaces an
earlier one says so.
